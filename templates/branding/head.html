Overrides the single favicon link mutint-core ships, because this project's templates dir is searched ahead of every app's -- the same mechanism as branding/footer.html. It has to be an override rather than a project `img/fav.png`: that filename is also the icon in core's "Powered by ALEdb" watermark, so shadowing it would restyle an attribution that is not this deployment's to change. `icon.svg` first and unsized: a browser that understands SVG icons prefers it at every size, and falls through to the .ico otherwise. `icon-16.svg` is the simplified mark drawn for that size -- three shapes where the full icon has fifteen, because the detailed one turns to mud at 16px. {% endcomment %}
