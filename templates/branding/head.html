{% load static %}{% comment %} MutInt's icons. Overrides the single favicon link mutint-core ships, because this project's templates dir is searched ahead of every app's -- the same mechanism as branding/footer.html. It has to be an override rather than a project `img/fav.png`: that filename is also the icon in core's "Powered by ALEdb" watermark, so shadowing it would restyle an attribution that is not this deployment's to change. **One SVG candidate, not two.** `sizes` is not honoured on an `image/svg+xml` icon link -- a browser that understands SVG icons treats it as any-size -- so two same-`rel` SVGs left it unspecified which one a 16px tab got, and it was as likely to be the detailed mark as the one drawn for that size. The one offered is `icon-16.svg`, the simplified mark: three shapes where the full icon has fifteen, because a tab is 16-32px and the detailed one turns to mud there. The `.ico` is for browsers with no SVG icon support and is the only file here that genuinely carries per-size artwork -- simplified at 16 and 32, full at 48. `icon.svg`, the full mark, stays on disk and is deliberately not linked: it is the source the MutInt.app bundle icon is rendered from. {% endcomment %}
